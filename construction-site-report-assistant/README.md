Construction Site Report Assistant

An AI-powered construction site reporting assistant designed to help organize, summarize, and process daily construction site reports more efficiently.

Overview

Construction projects generate a large amount of daily information, including work completed, materials received, equipment used, site activities, and observations.

The Construction Site Report Assistant is designed to simplify this process by helping users turn construction site information into structured and useful reports.

Features

- Process construction site report information
- Organize daily site activities
- Summarize construction updates
- Assist with construction documentation
- Support structured reporting
- Designed for future AI-powered report generation

Technologies

- Python
- Streamlit
- OpenAI API
- Pandas
- Python-dotenv

Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/construction-site-report-assistant.git

Navigate into the project directory:

cd construction-site-report-assistant

Install the required dependencies:

pip install -r requirements.txt

Environment Variables

Create a ".env" file in the project directory and add your API key:

OPENAI_API_KEY=your_api_key_here

Do not upload your real API key to GitHub.

Running the Application

Run the application with:

streamlit run app.py

The application will open in your browser.
